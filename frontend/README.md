# 🚀 Codeflow

**Codeflow** is a powerful browser-based code editor (IDE) that lets you run frontend, backend, and fullstack applications instantly — without any setup.

> ⚡ Build, run, and test code directly in your browser using WebContainers.

---

## 🌐 Live Demo
👉 https://your-app.netlify.app

---

## ✨ Features

- 🧑‍💻 Online Code Editor (Monaco Editor)
- ⚡ Run code instantly in browser
- 🖥️ Multi-terminal support (Dev Server, Shell, Backend)
- 📦 Built-in templates (React, Node.js, Express, Next.js, Astro)
- 🔄 Split editor support
- 🌐 Live preview
- 📁 Upload and run custom projects

---

## 🏗️ Tech Stack

- React.js
- Vite
- Tailwind CSS
- Monaco Editor
- WebContainers (StackBlitz)
- Xterm.js
- Netlify
